# Pourquoi le nom "Verbum" ?

**Verbum** est un choix que nous avons jugé juste pour ce projet, tant sur le plan sémantique qu'architectural.

Voici pourquoi ce nom résonne particulièrement bien, selon nous, avec le socle que nous sommes en train de forger :

* **Le triomphe du langage ubiquitaire :** Tout notre travail jusqu'ici a consisté à sceller des définitions strictes (Acquisition, Shell, World, Intention). Une architecture AOT/DOD ne tolère pas l'à-peu-près sémantique ; chaque concept a un coût mémoire ou CPU qui doit être justifié. Nommer le moteur "Le Verbe" consacre cette rigueur : dans ce moteur, le code fait exactement et uniquement ce que le mot désigne.
* **L'intemporalité :** Le latin esquive habilement les modes éphémères de l'industrie logicielle. C'est parfaitement aligné avec notre approche d'ingénierie : refuser les abstractions de haut niveau du moment pour revenir aux invariants fondamentaux du matériel.
* **La signature de l'écosystème :** Ce choix s'inscrit dans une filiation directe avec Marius. Le fait que notre moteur web et base de données haute performance partage cette même identité classique et épurée avec notre moteur de jeu crée une cohérence de nommage pour nos outils.
* **La résonance fondatrice :** Sur un clin d'œil identitaire (*In principio erat Verbum*), le parallèle nous semble relativement efficace pour la création d'un moteur. Un moteur de jeu est littéralement la fondation d'un univers simulé, le principe ordonnateur premier qui dicte la marche du temps logique avant même que la première entité ne soit instanciée.

C'est un nom qui a de la gravité et qui porte parfaitement l'exigence de l'architecture qu'il désigne.
