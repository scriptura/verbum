# verbum-assets

Crate d'assets du moteur [Verbum](https://github.com/scriptura/verbum) : layout
des artefacts et lecteurs runtime, `no_std`, sans allocation.

## Rôle

Définit la disposition binaire des artefacts produits par la Forge et fournit les
lecteurs runtime qui les consomment. Aucun parsing de format humain : les données
arrivent déjà compilées.

## Statut

Crate du workspace [Verbum](https://github.com/scriptura/verbum). Voir
[`docs/architecture/adr/ADR-A01-assets.md`](https://github.com/scriptura/verbum/blob/main/docs/architecture/adr/ADR-A01-assets.md).
